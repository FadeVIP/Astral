# Astral Atmosphere — Minecraft 1.20.1 / Forge 47

Клиентское оформление основной сборки Astral: космическое главное меню, меню паузы и экран подготовки ресурсов с фактическим прогрессом загрузки. Самое раннее окно Forge также получает ночной фон, звёзды и заголовок Astral при запуске через лаунчер 0.4.3.

Для раннего окна лаунчер подключает встроенный Java agent из этого же JAR только для основной сборки Forge 47.4.20. Агент заменяет два класса отрисовки в памяти после проверки SHA-256 оригиналов; библиотеки Forge на диске не изменяются. При другой версии классов оформление пропускается. Исходники изменений Forge и лицензия LGPL 2.1 включены в JAR (`astral-early/source`) и лежат в `early/`. Отключить раннее оформление в другом лаунчере можно удалением аргумента `-javaagent`; обычное меню мода продолжит работать.

Главное меню содержит только «Играть», «Сеть», «Настройки», «Выйти» и четыре значка: сайт Astral, Discord, Telegram, поддержка автора. Перед открытием внешней ссылки Minecraft показывает адрес и просит подтверждение. Кнопка «Сеть» открывает стандартный список серверов и LAN. Инвентарь, здоровье и остальные элементы игрового HUD не меняются.

Лаунчер 0.4.3 предлагает светлую, тёмную и звёздную темы в «Настройки → Твоя атмосфера». Выбор сохраняется на компьютере. Серверная карточка, опрос статуса, подключение к шлюзу и автоматическое добавление сервера отключены. Перед запуском основной сборки удаляется только её прежняя закреплённая официальная запись; резервная копия — `servers.dat.astral-disabled-backup`. Остальные записи не удаляются.

## Сборка и проверка

- `build.cjs` собирает `dist/astral-atmosphere-0.1.0.jar` с фактическими библиотеками установленной 1.20.1.
- `preview.cjs` создаёт отдельный тестовый экземпляр с собственными настройками, без пользовательских миров.
- `PreviewTest.java` упаковывается отдельным модом только для теста; в опубликованный JAR не входит.
- Тест снимает главное меню, загрузку и паузу, проверяет размеры и пересечения кнопок, затем открывает выбор локального мира через штатное действие кнопки.
- `preview.cjs --compact` проверяет окно 1280 × 720 с масштабом интерфейса 3.

Начиная с лаунчера 0.4.9, оформление основной сборки (`id: astral`, Minecraft 1.20.1, Forge 47.4.20) включено в EXE. Перед запуском лаунчер сравнивает JAR с комплектной копией и восстанавливает его, даже если администратор заменил базовый ZIP. Предыдущий JAR сохраняется в `.atmosphere-backups` рядом с папкой `minecraft`. Для обновления этой обязательной версии оформления нужно обновить комплектный JAR и выпустить лаунчер; содержимое ZIP или каталога не переопределяет его. Остальные сборки не затрагиваются.

Проверку пользовательского запуска выполняем через кнопку «Играть» в собранном EXE. `PreviewTest.java` допускается устанавливать только временно для проверки меню; он сам завершает Minecraft и не входит в распространяемый JAR.
