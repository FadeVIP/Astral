# Игра с друзьями: прямое соединение и резервный VPS

Все сборки Minecraft 1.20.1 / Forge 47.x, включая новые записи каталога. Нужны обновлённые лаунчер и комплектный Atmosphere у обоих участников. Сторонние VPN не нужны. Существующий Firebase Astral хранит список друзей, статусы и временные приглашения. Сначала проверяется прямой путь между компьютерами, затем используется собственный VPS Astral, если напрямую подключиться нельзя.

1. Добавьте друг друга в друзья через центр игрока лаунчера.
2. Хозяин запускает одиночный мир. В паузе выбирает «Друзья» → «Открыть мир друзьям».
3. Лаунчер пробует PCP, NAT-PMP и UPnP. При успехе показывает ответ роутера. Это ещё не подтверждает доступность через провайдера.
4. Друг в главном меню выбирает «Друзья» → «Запросить вход».
5. Хозяин открывает вкладку «Запросы» и разрешает вход. Друг нажимает «Подключиться».

Разрешение на новое подключение действует до истечения пятиминутного запроса. Уже установленное соединение продолжается до закрытия мира или доступа. Список обновляется примерно каждые 10 секунд, статус онлайн — до 90 секунд после последнего обновления лаунчера. Для подключения нужно сначала выйти из своего мира.

Кнопка «Закрыть доступ» разрывает туннели и удаляет созданное правило роутера. Само обычное LAN-открытие Minecraft сохраняется до выхода из мира. Оно не пробрасывается на роутере: наружу открывается только отдельный вход Astral с проверкой разрешения. Чужое правило UPnP не заменяется. PCP/NAT-PMP арендуются на 120 секунд и продлеваются; при сбое продления доступ закрывается. UPnP-правило записывается для повторной очистки после аварийного завершения.

## Ограничения

- При недоступности прямого пути используется TLS-посредник 91.240.175.14:24443.
- При CGNAT или втором роутере доступ через интернет может не появиться даже после успешного ответа домашнего роутера.
- Брандмауэр Windows может потребовать разрешения для лаунчера. Программа не отключает защиту компьютера.
- IPv6 и TCP hole punching пока не реализованы. Для резервного пути обоим ПК нужен исходящий TCP-доступ к VPS.
- Разрешение проверяется по случайному запросу и HMAC, секрет приглашения по игровому соединению не передаётся. Прямой путь не шифрует весь LAN-трафик; резервный путь защищён TLS на обоих участках через доверенный VPS.
- Сборки и версии модов участников должны совпадать.

## Проверка

Локальные проверки покрывают отказ неавторизованному клиенту, передачу бинарных данных, закрытие доступа, отклонение запросов браузера к локальному API и переход PCP → NAT-PMP на имитаторе роутера. В Firebase отдельными временными аккаунтами проверены запрос, разрешение, отказ, запрет самостоятельного подтверждения и чтения посторонним. Тестовые аккаунты удалены.

На текущем роутере автоматическое открытие порта не подтверждено. Передача 1 МиБ случайных данных через реальный VPS и отключение по закрытию доступа проверены. Полная игровая сессия между двумя внешними ПК ещё не проверена.

В дополнительных сборках комплектный мод устанавливает скины, косметику и кнопку друзей, сохраняя исходные меню и загрузку сборки. Полное оформление Astral применяется только к основной сборке. Minecraft 1.7.10 пока не поддерживается.
