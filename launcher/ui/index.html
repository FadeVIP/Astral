Главное меню — по твоим правилам

Меняй фон и кнопки. Игроки получат опубликованное оформление перед следующим запуском игры.

Макет 640 × 360. Нажми кнопку на макете, чтобы настроить её. В игре используется шрифт Minecraft; проверка не разрешит пересечение кнопок.

СТУДИЯ ASTRAL / АДМИНИСТРАТОР

Управление сборками

Опубликуй новый мир. Он появится у игроков без нового EXE.

Выбери сборку слева. Основная Astral редактируется полностью: ZIP, Minecraft, Forge, оформление и файлы. Исходная рабочая версия сохранена отдельно.

Новая сборка

GOOGLE DRIVE → КАТАЛОГ

Открой доступ «Все, у кого есть ссылка». В ZIP должна быть папка mods с файлами модов. Поддерживается и папка .minecraft внутри архива.

Укажи точную версию Forge из своей сборки или оставь пустой для рекомендованной. Java будет подобрана автоматически.

Фон сборки

PNG, JPG или WebP до 10 МБ. Лучше всего подойдёт горизонтальное изображение.

Сначала проверь архив — лаунчер рассчитает размер, число модов и контрольную сумму.

Добавить или заменить файл через Drive

Для файла в корне Minecraft укажи options.txt без названия папки. Он заменит все настройки игры один раз при получении нового содержимого; прежний файл сохранится в резервной копии. Следующие личные изменения игрока сохраняются.

Импортировать папку Google Drive

Импорт добавляет и заменяет файлы. Для удаления отметь их в списке ниже. Файлы на Google Drive остаются на месте.

Подключить Google Drive API — один раз на этом ПК
  1. В Google Cloud Console выбери свой проект.
  2. В «API и сервисы → Библиотека» включи Google Drive API.
  3. В «Учётные данные» создай API-ключ и ограничь его API «Google Drive API». Ключ используется только для чтения публичных папок.
  4. Открой папке и файлам доступ «Все, у кого есть ссылка» и вставь ключ ниже.

Служебный JSON Firebase и пароль Google здесь не нужны. Импорт отдельного файла выше работает без API-ключа.

Удаление и замена применяются только к отмеченным файлам. Миры и скриншоты не изменяются. Предыдущие версии изменённых файлов сохраняются в резервной копии. Совместимость модов проверяй в тестовой игре до публикации.

Играть с друзьями

Включено по умолчанию. Для игры через Astral открой «Друзья» в меню паузы, открой доступ к миру и прими запрос. Лаунчер сначала пробует прямое соединение, затем собственный VPS. Для обычной LAN можно открыть мир через меню Minecraft и передать адрес и порт. У хозяина тоже должна быть включена эта настройка; всем нужны разные ники и одинаковые моды. Изменения действуют после перезапуска игры.
