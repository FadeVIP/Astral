# Каналы обновления Astral

Игрок выбирает канал в «Настройки → Загрузки → Обновления лаунчера».
По умолчанию — стабильный. Тестовый канал добровольный и получает более новую из подписанных стабильной и предварительной версий. Отсутствующий предварительный выпуск не блокирует стабильное обновление. Возврат на стабильный канал не понижает установленную версию.

Для выпуска тестовой версии после обычной сборки, проверок и подписи:

```powershell
node launcher/tools/publish-launcher-hotfix.cjs --preview --curl-upload --theme-asset
```

Версия должна быть новой, числовой (например 0.5.2). Публикуется GitHub prerelease v0.5.2. Подписанный указатель канала находится в prerelease с тегом preview. Стабильный latest и ссылки на сайте остаются прежними. Перед публикацией тестового выпуска проверьте `RELEASE-NOTES.md` и содержимое приложения.

После проверки добровольцами продвиньте тот же неизменённый подписанный выпуск:

```powershell
node launcher/tools/publish-launcher-hotfix.cjs --promote --curl-upload --theme-asset
```

Не пересобирайте EXE между предварительным выпуском и продвижением: скрипт проверяет совпадение хешей опубликованных файлов. Обычная публикация без флагов остаётся стабильной. Указатель preview может оставаться на продвинутой версии: клиент сравнивает его со стабильным и выбирает более новую. Новая тестовая версия заменит только указатель preview; версионные файлы сохраняются.
